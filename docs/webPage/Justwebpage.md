# 주가 예측 웹서비스 - 웹페이지 구조 기획서 (Frontend 전용, API 제외)

> 이 단계에서는 실제 주가 데이터 API 연동, 차트 분석 로직, 예측 모델 등은 제외하고
> **웹페이지의 화면 구조(페이지 구성, 레이아웃, 컴포넌트, 사용자 흐름)만** 정의합니다.
> 이후 API/예측 기능이 붙을 자리는 "연동 예정" 형태로 표시만 해둡니다.

## 1. 페이지 구성 (사이트맵)

```
/                      메인 페이지 (홈)
/search                종목 검색 페이지
/stock/:id             종목 상세 페이지 (차트/예측/뉴스 자리)
/watchlist             관심 종목 페이지
/compare               종목 비교 페이지
/login                 로그인 페이지
/signup                회원가입 페이지
/mypage                마이페이지 (설정, 알림 등)
```

## 2. 페이지별 구조 및 화면 요소

### 2.1 메인 페이지 (`/`)
- 상단 네비게이션 바 (로고, 검색창, 로그인/마이페이지 버튼)
- 인기 검색 종목 리스트 (자리만, 더미 데이터)
- 관심 종목 요약 카드 (로그인 시)
- 서비스 소개 배너

### 2.2 종목 검색 페이지 (`/search`)
- 검색 입력창 (종목명/티커)
- 검색 결과 리스트 (종목명, 현재가 자리, 등락률 자리)
- 필터: 시장 구분(코스피/코스닥/미국 등) 탭

### 2.3 종목 상세 페이지 (`/stock/:id`)
- 종목 기본 정보 헤더 (종목명, 티커, 현재가 자리)
- 탭 구성:
  - **[과거 주가 분석]** 탭 → 차트 영역 (자리만, "API 연동 예정" 표시)
  - **[예측]** 탭 → 예측 그래프 + 관련 뉴스 리스트 영역 (자리만, "API/모델 연동 예정" 표시)
  - **[뉴스]** 탭 → 관련 뉴스 카드 리스트 (자리만)
- 관심 종목 등록 버튼 (UI만, 실제 저장은 추후 백엔드 연동)

### 2.4 관심 종목 페이지 (`/watchlist`)
- 등록한 종목 리스트 (테이블 또는 카드형)
- 종목별 알림 설정 버튼 (UI만)

### 2.5 종목 비교 페이지 (`/compare`)
- 비교할 종목 2~3개 선택 UI
- 비교 결과 표시 영역 (자리만)

### 2.6 로그인 / 회원가입 페이지
- 이메일/비밀번호 입력 폼
- 소셜 로그인 버튼 (UI만)

### 2.7 마이페이지 (`/mypage`)
- 회원 정보 표시/수정
- 알림 설정
- 관심 종목 관리 바로가기

## 3. 공통 컴포넌트 (재사용 요소)

- `Header` (네비게이션 바)
- `Footer`
- `SearchBar`
- `StockCard` (종목 요약 카드)
- `TabMenu` (상세 페이지 탭 전환용)
- `PlaceholderChart` (추후 실제 차트로 교체될 자리)
- `NewsCard` (뉴스 카드, 추후 실제 뉴스 데이터로 교체)
- `Button`, `Input`, `Modal` 등 기본 UI 요소

## 4. 사용자 흐름 (프론트엔드 기준)

1. 메인 페이지 접속
2. 검색창에서 종목 검색 → 검색 결과 페이지
3. 원하는 종목 클릭 → 종목 상세 페이지 이동
4. 상세 페이지 내 탭 전환 (과거 분석 / 예측 / 뉴스) - 현재는 자리만 표시
5. 관심 종목 등록 (로그인 시) → 관심 종목 페이지에서 확인

## 5. 기술 스택 제안 (Frontend 전용)
- React 또는 Next.js
- 스타일링: Tailwind CSS
- 라우팅: React Router (또는 Next.js 기본 라우팅)
- 상태 관리: 초기엔 useState/Context로 충분, 추후 필요 시 Redux/Zustand 고려
- 목업 데이터: 로컬 JSON 파일로 임시 대체 (실제 API 연동 전까지)

## 6. 이번 단계에서 제외한 항목 (추후 별도 기획)
- 실시간 주가 데이터 API 연동
- 차트 분석 로직 (이동평균, 거래량 등 실제 계산)
- 주가 예측 모델
- 뉴스 감성 분석 및 예측 근거 매칭 로직
- 백엔드/DB 연동, 인증 로직 실제 구현
