# 주가 분석 & 예측 사이트 — 디자인 가이드

참조 이미지: `uploads/pasted-1786026335030-0.png`
(다크 배경 + 그레인 오라 그라디언트 스타일. 레이아웃/카피는 우리 서비스에 맞게 재구성, 브랜드 요소는 사용하지 않음)

---

## 1. 톤 & 무드

- **다크 퍼스트.** 거의 검정에 가까운 남색 배경 위에, 화면 밖에서 스며드는 듯한 컬러 오라(aurora) 그라디언트.
- 그라디언트는 **장식이 아니라 조명**이다. 항상 콘텐츠 뒤/아래에 두고, 텍스트는 어두운 영역 위에 올린다.
- 금융 사이트지만 "터미널"이 아니라 **차분하고 고급스러운 프로덕트** 느낌. 빨강/초록 신호는 데이터에만, 배경에는 쓰지 않는다.
- 여백을 크게. 한 화면(섹션)당 메시지 하나.

## 2. 컬러

### 배경
| 역할 | 값 |
| --- | --- |
| 페이지 배경 | `oklch(0.16 0.02 275)` — 잉크 네이비 블랙 |
| 섹션 대체 배경 (스탯 바 등) | `oklch(0.19 0.02 275)` |
| 카드 표면 | `oklch(0.22 0.02 275 / 0.55)` + `backdrop-filter: blur(20px)` |
| 보더 | `oklch(1 0 0 / 0.10)` |

### 텍스트
| 역할 | 값 |
| --- | --- |
| 주요 텍스트 | `oklch(0.97 0.005 275)` |
| 보조 텍스트 | `oklch(0.72 0.01 275)` |
| 라벨/캡션 (대문자) | `oklch(0.58 0.01 275)` |

### 오라 그라디언트 (배경 전용)
동일 채도/명도 계열에서 색상(hue)만 순회시킨다. 4색을 넘기지 않는다.

```
--aura-warm:  oklch(0.62 0.15  35)   /* 코랄 */
--aura-magenta: oklch(0.55 0.17 320) /* 마젠타 */
--aura-violet: oklch(0.48 0.18 285)  /* 바이올렛 */
--aura-teal:  oklch(0.62 0.11 195)   /* 틸 */
```

### 데이터 컬러 (차트 전용)
| 의미 | 값 |
| --- | --- |
| 상승 | `oklch(0.75 0.14 165)` |
| 하락 | `oklch(0.66 0.17 20)` |
| 예측선 / 신뢰구간 | `oklch(0.70 0.13 285)`, 구간은 `alpha 0.18` |
| 중립 그리드 | `oklch(1 0 0 / 0.07)` |

## 3. 배경 만드는 방법 (핵심)

세 겹으로 쌓는다.

1. **베이스**: 페이지 배경 단색.
2. **오라**: 크게 번진 `radial-gradient` 2~3개를 겹치고, 컨테이너 밖으로 60~120% 넘치게 배치. `filter: blur(80–140px)`.
3. **그레인**: 전면에 노이즈 오버레이 (`opacity: 0.05–0.09`, `mix-blend-mode: overlay`). 이게 참조 이미지의 질감을 만드는 결정적 요소다.

```html
<!-- 히어로 배경 예시 -->
<div style="position:absolute; inset:-30% -10% auto -10%; height:90%;
  background:
    radial-gradient(60% 55% at 30% 20%, oklch(0.62 0.15 35 / .55) 0%, transparent 70%),
    radial-gradient(55% 50% at 62% 8%,  oklch(0.55 0.17 320 / .55) 0%, transparent 72%),
    radial-gradient(70% 60% at 88% 30%, oklch(0.62 0.11 195 / .50) 0%, transparent 75%);
  filter: blur(90px); pointer-events:none;"></div>

<!-- 그레인 -->
<div style="position:absolute; inset:0; opacity:.07; mix-blend-mode:overlay;
  background-image:url('data:image/svg+xml;utf8,<svg xmlns=\'http://www.w3.org/2000/svg\'>\
<filter id=\'n\'><feTurbulence type=\'fractalNoise\' baseFrequency=\'0.8\' numOctaves=\'3\'/></filter>\
<rect width=\'100%\' height=\'100%\' filter=\'url(%23n)\'/></svg>');"></div>
```

규칙
- 오라는 **위(히어로 상단)와 아래(섹션 하단)** 두 곳에만. 화면마다 다 넣으면 싸구려가 된다.
- 오라 위에 텍스트를 얹지 말고, 오라와 텍스트 사이에 어두운 영역을 확보한다.
- 참조처럼 카드가 오라를 가로지르게 두면 유리 질감이 살아난다 (카드 반투명 + blur).

## 4. 타이포그래피

- 폰트: 라틴 **Helvetica Neue / Helvetica**, 한글 **Pretendard**. 숫자는 `font-variant-numeric: tabular-nums` 고정.
- 히어로 타이틀은 초대형 + `letter-spacing: -0.03em`, `line-height: 0.95`. 참조처럼 아래로 갈수록 밝기가 떨어지는 그라디언트 텍스트(`background-clip: text`)를 히어로에만 1회 사용.

| 스타일 | 크기 / 굵기 |
| --- | --- |
| Hero | 96–128px / 500 |
| H2 (섹션) | 56–72px / 500 |
| H3 (카드 제목) | 24–28px / 500 |
| 본문 | 16–18px / 400, `line-height 1.6` |
| 라벨 | 12px / 500, `letter-spacing .12em`, 대문자 |
| 지표 수치 | 32–48px / 500, tabular |

## 5. 레이아웃 시스템

- 컨테이너 최대 1200px, 좌우 여백 40px(모바일 20px). 12컬럼, gap 24px.
- 수직 리듬: 섹션 패딩 120–160px. 히어로는 `min-height: 88vh`.
- 모든 형제 그룹은 flex/grid + `gap`. 인라인 여백 금지.
- 라운드: 카드 16px, 버튼 pill(999px), 차트 패널 20px.

### 홈페이지 섹션 순서
1. **히어로** — 상단 오라, 라벨("실시간 주가 분석 & 예측") + 초대형 타이틀 + pill CTA 2개(주요=흰 배경 검정 글씨, 보조=투명+보더).
2. **지표 바** — 배경 한 톤 밝게, 세로 구분선으로 4칸: 커버 종목 수 / 예측 정확도 / 업데이트 주기 / 데이터 소스.
3. **핵심 차트 데모** — 폭 넓은 유리 패널 하나. 실적 라인 + 예측 구간. 이 섹션이 제품의 증거다.
4. **기능 4카드** — 참조와 동일한 구조: 카드 열이 하단 오라를 가로지름. 각 카드 우하단에 `01–04` 큰 반투명 숫자.
5. **작동 방식** — 3스텝, 번호 + 짧은 문장.
6. **종목 리스트 / 워치리스트 프리뷰** — 표 형태, tabular 숫자, 상승/하락 컬러.
7. **CTA + 푸터** — 어두운 단색, 오라 없음. 면책 문구(투자 자문 아님) 필수.

## 6. 컴포넌트 규칙

- **버튼**: pill, 높이 44px 이상, 패딩 `12px 24px`. hover는 밝기 변화만(이동/확대 금지), `transition: 160ms ease`.
- **카드**: 반투명 표면 + 1px 보더 + `backdrop-filter: blur(20px)`. 그림자 대신 보더로 형태를 잡는다.
- **차트**: 축/그리드는 극도로 얇게. 예측 구간은 반투명 밴드, 예측선은 dashed. 툴팁은 카드와 같은 유리 표면.
- **표**: 행 구분선 `oklch(1 0 0 / .07)`, hover 시 행 배경 `oklch(1 0 0 / .03)`.

## 7. 이미지 / 오브젝트

- 참조의 유리 오브젝트 자리는 **플레이스홀더**로 둔다: 얇은 대각 스트라이프 + 모노스페이스 라벨(`glass object 01`). SVG로 직접 그리지 않는다.
- 실제 소재는 3D 유리 렌더 또는 종목 차트 스냅샷으로 나중에 교체.

## 8. 모션

- 진입: `opacity 0→1` + `translateY 12px→0`, 500ms, `cubic-bezier(.22,.61,.36,1)`, 80ms stagger.
- 오라는 아주 느리게(30–60s) 드리프트. 그 외 배경 애니메이션 없음.
- `prefers-reduced-motion` 시 모션 전부 제거.

## 9. 하지 말 것

- 배경 그라디언트를 카드/버튼/텍스트 채우기로 쓰기.
- 오라 위에 본문 텍스트 얹기.
- 상승/하락 외의 곳에 빨강·초록 사용.
- 이모지, 아이콘 남발, 근거 없는 숫자 나열.
- 배경색 3개 이상 사용.
